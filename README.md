# Synthetos community

Questions, answers and projects for Synthetos CNC motion controllers: **TinyG**, **gShield (grblShield)** and **g2core**.

**[Ask a question or browse discussions →](https://github.com/synthetos/community/discussions)**

## Before you post

- Search the [forum archive](https://synthetos.com/forum/) (2011–2025). Many common questions are answered there.
- Read the docs: [TinyG wiki](https://github.com/synthetos/TinyG/wiki), [g2core wiki](https://github.com/synthetos/g2/wiki), [gShield wiki](https://github.com/synthetos/grblShield/wiki).
- Found a firmware bug? Open an issue on [TinyG](https://github.com/synthetos/TinyG/issues) or [g2core](https://github.com/synthetos/g2/issues).

## Getting a good answer

Include:

- board and revision (for example TinyG v8, gShield v5)
- firmware version (`$fv` / `$fb` on TinyG)
- what the machine is doing, and what you expected
- power supply voltage and motor type
- any error messages, configs or photos

## Orders and warranty

For orders, shipping and warranty claims, use the [contact form](https://synthetos.com/contact/) rather than a public post.
